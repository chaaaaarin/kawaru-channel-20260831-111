採用対応の何が「10時間」なのか

返信が遅れる

手で1件ずつ返信。初回連絡が2〜3日遅れ、その間に応募者は他社の面接へ進む。

長文を読む

志望動機を1件ずつ読み、経験・資格・勤務条件を目で拾う作業が毎回発生。

状況が頭の中

「誰に返した」「次は誰」が担当者の記憶頼り。休むと止まる。

導入前 → 導入後
導入前
  • 初回返信まで2〜3日
  • 長い志望動機を1件ずつ読む
  • 選考状況は記憶頼り
→
導入後
  • 応募の数分後に面接案内
  • 経験・強み・勤務条件の3行要約が届く
  • ステータス列で一覧に

※「10時間→10分」は配布ワークシートに書かれた作り手の実績値。第三者検証はしていません。

作り方（3ステップ）

① やりたいことを「言葉」で渡す

背景 → データの形 → 処理の順番 → 条件 の4つを書けば、コードは書けます。

# プロンプト①（配布ワークシートより）
あなたはGoogle Apps Scriptの専門家です。以下の仕様でコードを書いてください。
# 背景 採用。応募への初回連絡が遅れ、応募者が他社へ流れている。
# シートの構成 「応募シート」A列=タイムスタンプ / B列=氏名 / C列=メール …
# 処理の流れ 未返信の行に、設定タブの件名・本文で自動返信メールを送る …
# 条件 初心者向けに日本語コメントを入れ、使い方も説明して
② まず「自動返信だけ」動かす（第1形態）

いきなり全部を作らず、自動返信マシンだけを先に完成。APIキーがなくても動きます。返ってきたコードは「拡張機能 → Apps Script」を開いて貼り、保存 → 実行。初回だけ「このアプリを許可しますか」に承認します。

③ AI要約と担当者通知を足す（第2形態）

動いているコードに「志望動機を Gemini で要約 → 担当者へ通知」を追記依頼。Gemini APIキーは Google AI Studio（aistudio.google.com）で無料発行できます（「AIza…」で始まる文字列）。

# プロンプト②
先ほどのコードは正しく動きました。この動いているコードに機能を追加してください。
・自動返信のあと、志望動機を Gemini API で要約する
・採用担当へ「氏名・希望職種・要約・原文」つきの通知メールを送る
・「AI要約は参考情報。合否判断に使わない」と本文に明記する

なぜAIが2つ？ コードを書くのが Codex（作るときだけ・1回）、応募内容を要約するのが Gemini（動くたびに毎回呼ばれる・ずっと使う）。役割が違います。

🎁 プロンプト①②③の全文と、動作確認済みのコード見本は、配布ワークシート（プレゼント）に入っています。受け取り方は最後のセクションで。
5

AIが落ちても止まらない設計

この仕組みの一番のポイントが エラー分離。「① 応募者への自動返信」と「② AI要約＋担当者通知」を 別々のかたまり（try-catch） に分けます。Geminiが落ちても、応募者への返信は絶対に止めない。要約が失敗したら「要約なし（APIエラー）」と記録し、担当者へは志望動機の原文つきで通知します。

鈴木 健太送信済み要約なし（APIエラー）
2人目の「要約なし（APIエラー）」は失敗例ではなく設計どおりの動き。AIが止まっても、自動返信と担当者通知は届いている。
エラーが出たら「貼り返す」だけ
# プロンプト③（お直し用）
先ほどのコードを実行したら、以下のエラーが出て動きませんでした。
バグを修正して、原因を初心者向けに説明してください。修正後のコードは全文で。
【ここにエラーメッセージをそのまま貼り付ける】

※ エラー文を貼れば大抵直りますが、「何をしたい仕組みか」を最初に説明できていることが前提。直ったコードも送信先・条件は目視確認します。

FAQ／今日からやること

プログラミングの知識は本当に要らない？
コードを書く必要はありません。「何をしたい仕組みか」を言葉で説明する力と、結果を目視確認する姿勢は要ります。
全部無料でできますか？
スプレッドシート・GAS・Gemini無料枠で始められます。実務でCodexを回すなら月$20が目安。個人情報を扱うならGeminiの有料ティアも検討します。
AIの要約をそのまま選考に使っていい？
使わないでください。要約は担当者が確認しやすくするための参考情報です。
今日からやること（この順番で）
  • 1配布ワークシートを「コピーを作成」して自分のドライブに置く
  • 2応募シートに自分のメールを入れ、プロンプト①でコードを作らせる
  • 3Apps Scriptに貼って実行 → 自分宛にメールが届くのを確認（第1形態）
  • 4AI Studioで無料APIキーを取り、プロンプト②で要約＋通知を追加（第2形態）
  • 5本物のフォームを作り、回答先をこのシートにして列を合わせる

⚠️ この資料の確度

  • ✅ 公式ドキュメントで確認済み／⚠️「10時間→10分」「8〜10万円で納品」は作り手の実績談
  • Codexのプラン別レート上限の具体数値は公開ページに無く、AI Studio／Settings画面で確認する形
  • 仕様は変わります。最終確認は各公式サイトで。
