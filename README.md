## TL;DR（まず3行で）

1. 採用の応募が入ると「数分で自動返信 → AIが志望動機を3行に要約 → 採用担当へ通知 → ステータス列で一覧管理」する仕組みを、**スプレッドシート＋Google Apps Script＋Gemini（全部無料枠）** で作る。
2. その仕組みのコードは、**やりたい動作を日本語の仕様書にして Codex に渡す**だけで手に入る。コードは書かない。エラーが出たらエラー文を貼り返して直す。
3. キモは **エラー分離設計**。AI要約が失敗しても、応募者への自動返信は絶対に止めない作りにする。

> ⚠️「10時間→10分」「介護施設に8〜10万円で納品」は配布ワークシートに書かれた**作り手の実績談**で、第三者検証はしていません。

## 1. この動画で作る仕組みの全体像

採用の応募が1件入ってから、次の流れが自動で走ります。

| 段階 | やること |
|---|---|
| ① 応募が入る | Googleフォームの回答が、スプレッドシートの1行になる |
| ② 自動返信 | 未返信の行に、面接日程つきの案内メールを数分以内に送る |
| ③ AIが要約 | 志望動機・自己PRを「経験・強み・勤務条件」の3行に要約する |
| ④ 担当へ通知 | 採用担当へ「氏名・希望職種・要約・原文」つきの通知メールを送る |
| ⑤ 一覧管理 | ステータス列（連絡済／面接調整中…）で選考状況を一覧にする |

土台は3つ、いずれも無料で用意できます。

- **Googleスプレッドシート** … 応募の管理表
- **Google Apps Script（GAS）** … スプレッドシートやGmailを操作する小さなプログラム。インストール不要、Googleのサーバー上で動く（✅ [Apps Script 概要](https://developers.google.com/apps-script/overview?hl=ja)）
- **Gemini API** … 志望動機を要約するAI。Google AI Studio で無料のキーを発行できる

## 2. 採用対応の何が「10時間」なのか

配布ワークシートが想定するのは「従業員20名の介護施設の採用」です。そこで起きていること:

- **返信が遅れる** … 担当者が応募1件ごとに手で返信。初回連絡が2〜3日遅れ、その間に応募者は他社の面接へ進んでしまう。
- **長文を読む** … 志望動機・自己PRを1件ずつ読み込み、経験・資格・勤務条件（夜勤の可否など）を目で拾う作業が毎回発生する。
- **状況が頭の中にある** … 「誰に返した」「次は誰の面接」が担当者の記憶頼り。担当者が休むと止まる。

導入後は、応募の数分後に面接案内が届き、3行要約が担当者のメールに入り、ステータス列で選考状況が見えるようになります。

> ⚠️ ただし、応募が1日に数百件を超える規模だと、後述のメール送信上限に当たります（[8章](#8-どこまで使える向かない場面)）。

## 3. Codexとは／いくらかかるのか

**Codex（コーデックス）** は、OpenAI の「コードを書く・直す・仕上げるAIエージェント」です。ChatGPT のアカウントでログインして使います。動く場所は4つ:

| サーフェス | どんなもの |
|---|---|
| ターミナル（CLI） | 黒い画面にコマンドで操作。無料インストール。この動画で使うのはこれ |
| エディタ拡張 | VS Code などのコードエディタの中で使う |
| デスクトップアプリ | ChatGPTアプリの「Codexモード」。長い作業の管理向け |
| Web / クラウド | ブラウザで指示し、クラウド上で並列実行 |

**Codex は無料プランを含む全 ChatGPT プランに同梱**されています（✅ [Using Codex with your ChatGPT plan](https://help.openai.com/en/articles/11369540-using-codex-with-your-chatgpt-plan)）。プランで変わるのは使用量の上限だけです。

| プラン | 月額 | Codex |
|---|---|---|
| 無料版 | $0 | 上限つきで使える（まず試すならここ） |
| Go | $8 | メッセージ枠が拡大 |
| Plus | $20 | Codexの利用上限が拡大（実務で使うならここ） |
| Pro | $100〜 | Codexの最大タスク数（開発がメインの人向け） |

（✅ 2026-08-31 時点の [ChatGPT 料金ページ](https://chatgpt.com/pricing) 実測。既定モデルは GPT-5.6 系）

**⚠️ 良い面だけではありません。**

- 無料はすぐ上限に当たる。実務で回すなら $20 の Plus が目安。
- 生成されたコードは、中身を見ないまま動かさない。動いても意図と違う・穴があることがある。個人情報を扱う処理なら特に。
- モデルは入れ替わる。2026年8月末に Codex の旧モデルが終了し、新モデルへ自動で切り替わりました。挙動が変わることがあります（🔶 同ヘルプ記事 FAQ）。

## 4. 作り方①：やりたいことを「言葉」で渡す

Codex に渡すのは、**日本語の仕様書**です。次の4つを書けば、コードは書けます。

- **背景** … どんな業務で、何が困っているか
- **データの形** … どのシートの、どの列に、何が入っているか
- **処理の順番** … 1. 〜する 2. 〜する … と手順で書く
- **条件** … 「初心者向けに日本語コメントを入れて」「使い方も説明して」など

配布ワークシートのプロンプト①（第1形態を作る文）は、この型そのものです。

```text
あなたはGoogle Apps Script（GAS）の専門家です。以下の仕様でGASコードを書いてください。

# 背景
介護施設の採用業務です。応募への初回連絡が2〜3日遅れ、応募者が他社へ流れています。
まず「応募者への自動返信」を自動化したいです。

# シートの構成
シート名「②応募シート」：A列タイムスタンプ／B列氏名／C列メールアドレス／…（略）
シート名「③設定」：B4=担当者メール／B5=自動返信の件名／B6=自動返信の本文（{氏名}は名前に置換）

# 処理の流れ
1. メニュー「採用自動化メニュー」→「新着応募を処理」を追加する
2. H列が空でC列に@を含む行に、応募者へ自動返信メールを送る
3. 送信できたらH列に「送信済み」、G列に「連絡済」、A列に処理日時を記録する
4. 最後に「◯件の応募に自動返信しました」とポップアップ表示する

# 条件
・初心者にも分かるよう日本語コメントを入れ、コードの後に使い方も説明してください
```

**GAS（Google Apps Script）とは**：Google Workspace（Gmail・カレンダー・スプレッドシート等）と連携する小さなプログラムを作る仕組み。言語は JavaScript。**インストール不要**で、ブラウザの中のエディタで書き、**Google のサーバー上で実行**されます。自分の PC やサーバーは要りません。Google アカウントがあれば追加費用なしで使えます（✅ [Apps Script 概要](https://developers.google.com/apps-script/overview?hl=ja)）。

返ってきたコードは「貼るだけ」です。

1. Codex が書いたコードを全部コピーする
2. スプレッドシートの「拡張機能」→「Apps Script」を開く
3. 中身を全部消して貼り付け、保存する
4. 実行 → 初回だけ「このアプリを許可しますか」に承認する

これで、スプレッドシートに「採用自動化メニュー」が増えます。

## 5. 作り方②：まず「自動返信だけ」動かす（第1形態）

いきなり全部を作らず、**「自動返信マシン」だけ**を先に完成させて動かします。

- APIキーがなくても動く
- 「自分宛にメールが届く」まで確認してから次へ進む
- 動く土台に、あとから機能を足す

**なぜ2段階に分けるのか。** 一度に全部作ると、どこで失敗したのか分からなくなります。小さく動かして確かめる方が、初心者ほど速い。配布ワークシートも「第1形態 → 第2形態」の順で組んであります。

実演で追う手順:

1. 応募シートに、自分のメールアドレスを1行入れる
2. プロンプト①を Codex に貼る → 返ってきたコードを Apps Script へ
3. 「採用自動化メニュー」→「新着応募を処理」を実行
4. 自分宛に面接案内メールが届く。シートのステータスが「連絡済」になる

## 6. 作り方③：AI要約と担当者通知を足す（第2形態）

動いているコードに、**追記を頼みます**。ゼロから作り直しません。

```text
先ほどのGASコードは正しく動きました。ありがとうございます。
この動いているコードに、機能を追加してください。

# 追加したい機能
自動返信を送った後に、F列の志望動機・自己PRをGemini APIで要約し、採用担当へ通知メールを送りたいです。

# 追加の仕様
1. ③設定シートのB3セルにGemini APIキーが入っています
2. Gemini API（モデルは gemini-2.5-flash）で要約する
   要約の指示：採用担当者向けに、応募者の強み・経験・注目ポイントを3行以内で要約。
   資格や勤務条件（夜勤可否など）があれば必ず含める。合否の判断や推奨はしないこと
3. 要約結果をI列に書き込み、担当者へ「氏名・希望職種・要約・原文」つきの通知メールを送る
4. 通知メールに「※AI要約は参考情報です。合否判断には使わないでください」と明記する
```

**なぜAIが2つ出てくるのか。**

| | Codex | Gemini |
|---|---|---|
| 役割 | GASのコードを書く・直す | 応募内容をその場で要約する |
| いつ使う | 作るときだけ（基本1回） | 仕組みが動くたびに毎回呼ばれる（ずっと使う） |

**Gemini APIキーの取り方**：Google AI Studio（aistudio.google.com）を開く → APIキーを発行（「AIza…」で始まる文字列）→ ワークシートの「設定」タブに貼り付ける。

> ⚠️ **APIキーの管理**：キーはシートに直書きします。他人にシートを共有するときは、**必ずキーを消してから**。応募者の個人情報を含むので、シートの共有は採用担当だけに絞ります。

## 7. AIが落ちても止まらない設計

この仕組みで一番大事なのが **エラー分離** です。

- 「① 応募者への自動返信」と「② AI要約＋担当者通知」を、**別々のかたまり（try-catch）** に分ける
- Gemini API がエラーでも、**応募者への自動返信は絶対に止めない**
- 要約が失敗したら、要約欄に「要約なし（APIエラー）」と書き、担当者へは**志望動機の原文つきで**通知する

配布ワークシートの「⑥完成形見本」は、これを見せるために作られています。

| 氏名 | 自動返信 | AI要約・注目ポイント |
|---|---|---|
| 田中 美咲 | 送信済み | デイサービス3年の経験者。介護福祉士の有資格者。夜勤対応可能。 |
| 鈴木 健太 | 送信済み | **要約なし（APIエラー）** |

2人目の「要約なし（APIエラー）」は**失敗例ではなく、設計どおりの動き**です。AIが止まっても、自動返信（送信済み）と担当者通知は届いています。

**エラーが出たら「貼り返す」だけ。**

```text
先ほどのGASコードを実行したら、以下のエラーが出て動きませんでした。
バグを修正して、原因を初心者向けに報告してください。修正後のコードは全文を書いてください。
なお「応募者への自動返信はAPIエラーでも止めない」という設計条件は必ず維持してください。

# エラー内容
【ここにエラーメッセージをそのまま貼り付ける】
```

> ⚠️ エラー文を貼れば大抵は直りますが、「何をしたい仕組みか」を最初に説明できていることが前提です。直ったコードも、送信先や条件が合っているかは自分で目視確認します。

## 8. どこまで使える／向かない場面

### 個人情報をAIに渡してよいのか

Gemini API の料金ページには、こう書かれています（✅ [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)）。

| ティア | データの扱い |
|---|---|
| 無料 | Content used to improve our products（送った内容が Google の製品改善に使われる） |
| 有料 | Content not used to improve our products（送った内容は製品改善に使われない） |

無料の Gemini APIキーで応募者の氏名・電話番号・志望動機を処理すると、その内容が学習に使われうる、ということです。個人情報を扱うなら、**有料ティアに切り替える／応募者に断りを入れる**などの判断が要ります。gemini-2.5-flash の有料料金は、入力 $0.30・出力 $2.50 ／100万トークンです。

### 送信・実行時間の上限

Apps Script には1日あたりの割り当てがあります（✅ [Google サービスの割り当て](https://developers.google.com/apps-script/guides/services/quotas?hl=ja)、「予告なく変更あり」と明記）。

| 項目 | 一般アカウント（gmail.com） | Google Workspace |
|---|---|---|
| 1日あたりのメール送信先数 | **100 / 日** | 1,500 / 日 |
| スクリプト1回の実行時間 | 6分 / 回 | 6分 / 回 |
| トリガー合計の実行時間 | 90分 / 日 | 6時間 / 日 |

採用応募（1日数件）なら無料 Gmail の100通/日で十分です。ただし「大量にメールを送る」用途には天井があります。

### メリット・デメリット総まとめ

| 良い面 | 注意点 |
|---|---|
| 返信の遅れが数分に。取りこぼしが減る | 無料 Gemini API は内容が学習に使われうる |
| 長い志望動機が3行要約で届く | 無料 Gmail は送信100通/日、GAS実行6分/回 |
| スプレッドシート＋GAS＋Gemini無料枠で完結 | AI要約は誤る。合否判断には使わない |
| AIが落ちても業務は止まらない設計にできる | 生成コードは中身をレビューしてから使う |

## 9. 本物のフォーム接続／他の仕事へ

練習用シートで動いたら、本物の Google フォームにつなぐのは「列を合わせるだけ」です。

1. **フォーム作成** … 氏名・メール・希望職種・志望動機 の質問を並べる
2. **回答先を指定** … 回答をこのスプレッドシートに保存する設定にする
3. **列を合わせる** … 回答の列順を、応募シートの構成に合わせる
4. **そのまま動く** … 応募が入るたびメニューを実行（時間主導トリガーで自動実行も可）

同じ型は **日程調整・資料請求対応・予約受付** にも使えます。「受け取る → 定型で返す → 担当に回す → 記録する」は、どの業務でも同じ流れだからです。

> 同じことは Claude Code（クロード コード）や Gemini のコード生成でもできます。今回は Codex の例です。
>
> ⚠️ 配布ワークシートは「介護施設に8〜10万円で納品した仕組み」とされていますが、これは**作り手の実績談**で、第三者検証はしていません。

## 10. 今日からやること（この順番で）

1. 配布ワークシートを「ファイル → コピーを作成」して、自分のドライブに置く
2. 応募シートに自分のメールを入れ、プロンプト①で Codex にコードを作らせる
3. Apps Script に貼って実行 → 自分宛にメールが届くのを確認する（第1形態）
4. Google AI Studio で無料 APIキーを取り、プロンプト②で要約＋通知を追加する（第2形態）
5. 本物のフォームを作り、回答先をこのシートにして列を合わせる

- やりたい動作を「背景・データの形・処理の順番・条件」の4項目で書けば、Codex がコードにしてくれる。コードは書かない。

## 🎁 プレゼント（3点）と受け取り方

このテーマを「読んで終わり」にしないための配布物を用意しました。

1. **採用対応 自動化ワークシート**（Googleスプレッドシート）— 応募シート・設定・プロンプト集・動作確認済みのコード見本（第1形態／完成形態）・完成形見本の入った、この動画の仕組みが丸ごと入ったシート。「ファイル → コピーを作成」でその日から使えます。
2. **Codex仕様書ジェネレーター（アプリ）** — 「どのシート／どの列／何をトリガーに／何をする／エラー時どうする」を入力すると、Codex にそのまま貼れる日本語の仕様書ができます。採用対応以外の GAS 自動化にも使えます。
3. **「AIに任せる前」安全＆品質チェックリスト** — 個人情報をAIに渡してよいかの判定、APIキー管理、無料／有料ティアの選択、AI要約の免責明記、送信上限の確認。作る前と、人に渡す前の2段階で使います。

受け取りは **[プレゼント図書館（Kawaruチャンネル）](https://chaaaaarin.github.io/gift-library/aa/ep/111/)** から。受け取りには LINE 登録が必要です。
